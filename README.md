# Меню-консоль для работы с базовыми операциями Python

## Описание

Консольное приложение с иерархическим меню, реализующее набор типовых задач на Python:
- строковые и списковые операции
- работа с текстовыми файлами
- сериализация/десериализация словарей через **Pickle** и **JSON**

Проект выполнен в рамках **Варианта №9**.

---

## Стек технологий

| Компонент | Версия  |
|-----------|---------|
| Python    | 3.13.9  |
| `json`    | встроен (стандартная библиотека) |
| `pickle`  | встроен (стандартная библиотека) |

> Внешние зависимости отсутствуют. Для запуска достаточно стандартной установки Python.

---

## Инструкции по запуску

1. Убедитесь, что установлен Python 3.10 или выше:
   ```bash
   python --version
   ```
2. Перейдите в папку с проектом:
   ```bash
   cd путь/к/папке
   ```
3. Запустите главный файл:
   ```bash
   python ui.py
   ```
4. Следуйте подсказкам в меню, вводя номер нужного пункта.

## Краткая справка

### Главное меню

| № | Раздел |
|---|--------|
| 1 | Базовые операции |
| 2 | Работа с текстовым файлом |
| 3 | Сериализация |
| 0 | Выход |

### 1. Базовые операции

| № | Действие |
|---|----------|
| 1 | Вычислить тестовые строковые выражения |
| 2 | Вывести символы строки с их индексами |
| 3 | Преобразовать список чисел в одно число |
| 4 | Удалить ключ из словаря |
| 5 | Удалить дубликаты из списка |
| 6 | Показать текущий словарь |

### 2. Работа с текстовым файлом

| № | Действие |
|---|----------|
| 1 | Добавить текст в файл `test.txt` |
| 2 | Прочесть и вывести весь файл |
| 3 | Прочесть последние N строк файла |

### 3. Сериализация

| № | Действие |
|---|----------|
| 1 | Сохранить словарь через Pickle |
| 2 | Загрузить словарь из Pickle-файла |
| 3 | Сохранить словарь через JSON |
| 4 | Загрузить словарь из JSON-файла |
